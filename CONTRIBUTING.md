# Contributing

This library is maintained for the needs of the app that uses it. Contributions are welcome, but there is no promised roadmap, support
window or response time.

Please open an issue before starting anything beyond a small fix, so the scope can be agreed first. A new format or a parser fix should come
with a test that builds a file the way the tool writes it, and a note in `CHANGELOG.md`; a change that alters what is extracted from an existing
file also bumps `MediaMetadataExtractor.parserVersion`.
